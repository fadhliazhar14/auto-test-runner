📋 Project Overview

🎯 What is Auto Test Runner?

Auto Test Runner adalah enterprise-grade desktop application yang dibangun untuk mengelola dan menjalankan BDD (Behavior Driven Development) test scenarios menggunakan Cucumber dan Selenium WebDriver. Aplikasi ini menyediakan GUI yang user-friendly untuk create, edit, dan execute automated testing scenarios dengan real-time monitoring dan comprehensive reporting.

🖥️ Desktop Application

Professional Swing GUI dengan modern design, real-time updates, dan intuitive user experience untuk test management.

🔄 BDD Integration

Full Cucumber support dengan Gherkin syntax, dynamic step management, dan automated test execution engine.

🌐 Web Automation

Selenium WebDriver integration untuk automated browser testing dengan screenshot capture dan error handling.

🗄️ Database Driven

MySQL database dengan HikariCP connection pooling untuk persistent data storage dan team collaboration.

🗄️ Database Schema

📊 Entity Relationship

scenario (1) ──────── (N) step │ │ └─── (1) ──────── (N) execution_result

📋 Table Structures

🎭 Scenario Table

CREATE TABLE scenario ( id BIGINT AUTO_INCREMENT PRIMARY KEY, feature_name VARCHAR(255) NOT NULL, scenario_name VARCHAR(255) NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, UNIQUE KEY unique_scenario (feature_name, scenario_name) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

👣 Step Table

CREATE TABLE step ( id BIGINT AUTO_INCREMENT PRIMARY KEY, scenario_id BIGINT NOT NULL, step_type VARCHAR(10) NOT NULL, -- Given, When, Then, And step_text TEXT NOT NULL, step_order INT NOT NULL, FOREIGN KEY (scenario_id) REFERENCES scenario(id) ON DELETE CASCADE, INDEX idx_scenario_order (scenario_id, step_order) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

📈 Execution Result Table

CREATE TABLE execution_result ( id BIGINT AUTO_INCREMENT PRIMARY KEY, scenario_id BIGINT NOT NULL, status VARCHAR(20) NOT NULL, -- PASS, FAIL, PENDING log_path VARCHAR(500), screenshot_path VARCHAR(500), error_message TEXT, execution_time_ms BIGINT DEFAULT 0, executed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (scenario_id) REFERENCES scenario(id) ON DELETE CASCADE, INDEX idx_scenario_executed (scenario_id, executed_at DESC) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

🛠️ Setup & Installation

📋 Prerequisites

Java 17+

Oracle JDK atau OpenJDK 17 atau versi lebih tinggi. Pastikan JAVA_HOME sudah di-set dengan benar.

MySQL 8.0+

MySQL Server dengan user privileges untuk create database. Default port 3306 harus available.

Maven 3.6+

Apache Maven untuk dependency management dan build process. Pastikan tersedia di system PATH.

Chrome Browser

Google Chrome untuk Selenium WebDriver automation. ChromeDriver akan didownload otomatis.

⚙️ Installation Steps

1️⃣ Database Setup

# Jalankan MySQL server sudo systemctl start mysql # Linux net start mysql # Windows # Login ke MySQL (opsional - database akan dibuat otomatis) mysql -u root -p CREATE DATABASE bdd_test_runner;

2️⃣ Configuration

Edit file src/main/resources/database.properties:

# Database Connection Settings db.url=jdbc:mysql://localhost:3306/bdd_test_runner?useSSL=false&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true&serverTimezone=UTC db.username=root db.password=your_mysql_password db.driver=com.mysql.cj.jdbc.Driver # HikariCP Settings db.pool.maximumPoolSize=10 db.pool.minimumIdle=5 db.pool.connectionTimeout=30000

3️⃣ Build & Run

# Navigate to project directory cd C:\Users\User\Fadhli_DIR\BelajarJava\auto-test-runner # Clean and compile mvn clean compile # Run application mvn exec:java -Dexec.mainClass="com.fadhli.automation.BddTestRunnerApplication" # Alternative: Build JAR dan jalankan mvn clean package java -jar target/bdd-test-runner-1.0.0.jar

🎉 First Run

Saat pertama kali dijalankan, aplikasi akan:

  • Test koneksi ke MySQL database
  • Create database schema otomatis
  • Initialize connection pool
  • Launch GUI interface

📖 Usage Guide

🚀 Getting Started

1️⃣ Main Interface

📊 Scenario Table

Displays all BDD scenarios dengan columns:

  • Feature Name
  • Scenario Name
  • Steps Count
  • Created Date
  • Last Updated

🛠️ Action Buttons

  • Create New: Tambah scenario baru
  • Edit: Modify scenario yang dipilih
  • Delete: Hapus scenario
  • Run Test: Execute automation test
  • Refresh: Reload data dari database

2️⃣ Creating Scenarios

Step 1: Click "Create New" button Step 2: Fill in Feature Name dan Scenario Name Step 3: Add test steps: - Select step type: Given, When, Then, And - Enter step description - Click "Add Step" untuk menambah step baru Step 4: Click "Save" untuk menyimpan ke database

3️⃣ Running Tests

Test Execution Process:

  1. Pilih scenario dari table
  2. Click "Run Test" button
  3. Execution Console akan terbuka
  4. Monitor live log output dan progress
  5. View hasil test (PASS/FAIL) dan screenshots
